# scanner_alumny_back
API REST Django pour l'outil de diagnostic financier interne d'Alumny. Gère l'enrichissement par SIRET, le pipeline d'OCR et d'extraction de documents (LLM Vision local), les moteurs de calcul spécifiques par secteur (BTP, Services, Industrie), les agents IA de validation et la génération de rapports d'audit en PDF.
